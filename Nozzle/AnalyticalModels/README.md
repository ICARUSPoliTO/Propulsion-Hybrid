# Analytical Models

This folder contains analytical and semi-analytical models used to
describe the internal ballistics, thermodynamic behavior, and
system-level performance of the hybrid rocket motor.

The models implemented here are used to generate time-dependent
operating conditions and reference performance estimates that are
subsequently employed for comparison with CFD results and for the
definition of transient boundary conditions.

## File description

- chamber_pressure.py  
  Analytical internal ballistics model used to compute the chamber
  pressure evolution as a function of time, based on fuel regression
  laws, oxidizer properties, and feeding system assumptions.

- epsilon.py  
  Analytical model used to compute the nozzle expansion ratio and
  related geometric and thermodynamic quantities under prescribed
  operating conditions.

- Performance_V1_1.py  
  Zero-/one-dimensional analytical performance model used to estimate
  global nozzle and engine performance parameters (e.g. thrust
  coefficient, efficiency), providing reference results for comparison
  with CFD-based analyses.

- inputs.json  
  Unified input configuration file defining physical properties,
  geometric parameters, combustion models, feeding system assumptions,
  and numerical settings for the analytical simulations.

- results.pkl  
  Serialized output file storing the results produced by the analytical
  models, including time histories of chamber pressure and temperature
  as well as derived performance quantities. This file is mainly used
  for post-processing and model-to-CFD comparison.

- pc_vs_time_Pa.csv  
  Time history of chamber pressure generated by the analytical model
  and used as input for transient CFD boundary conditions.

- Tc_vs_time_K.csv  
  Time history of chamber temperature generated by the analytical model
  and used as input for transient CFD boundary conditions.
