# Analytical Models and Boundary Condition Generation

This folder contains analytical and semi-analytical models used to
describe the internal ballistics, thermodynamic behavior, and
system-level performance of the hybrid rocket motor.

In addition to performance estimation, the models implemented here
are responsible for generating time-dependent operating conditions
that are directly used as boundary conditions in CFD simulations.

## Scope

The analytical models defined in this folder are used to:
- Compute chamber pressure and temperature time histories
- Define the nozzle expansion ratio under on-design conditions
- Provide reference performance estimates for comparison with CFD
- Generate physically consistent transient boundary conditions

## File description

### Analytical models

- chamber_pressure.py  
  Internal ballistics model used to compute the time evolution of
  chamber pressure and temperature based on fuel regression laws,
  oxidizer properties, and feeding system assumptions.
  This script generates the pressure and temperature histories used
  in CFD simulations.

- epsilon.py  
  Analytical model used to compute the nozzle expansion ratio and
  related thermodynamic quantities under on-design conditions.

- Performance_V1_1.py  
  Zero-/one-dimensional analytical performance model used to estimate
  global engine and nozzle performance parameters (e.g. thrust
  coefficient, efficiencies), providing reference results for
  comparison with CFD-based analyses.

### Input and output files

- inputs.json  
  Unified input configuration file defining physical properties,
  geometric parameters, combustion models, feeding system assumptions,
  and numerical settings for the analytical simulations.

- results.pkl  
  Serialized output file storing the results produced by the analytical
  models, including time histories of chamber pressure and temperature
  as well as derived performance quantities. This file is used for
  post-processing and model-to-CFD comparison.

### Boundary condition data and UDFs

- pc_vs_time_Pa.csv  
  Time history of chamber pressure generated by `chamber_pressure.py`
  and used as input for transient CFD boundary conditions.

- Tc_vs_time_K.csv  
  Time history of chamber temperature generated by `chamber_pressure.py`
  and used as input for transient CFD boundary conditions.

- pc_time_bc.c  
  User-defined function (UDF) used in ANSYS Fluent to impose the
  time-dependent chamber pressure at the nozzle inlet.
  The pressure evolution is read from `pc_vs_time_Pa.csv`.

- Tc_time_bc.c  
  User-defined function (UDF) used in ANSYS Fluent to impose the
  time-dependent chamber temperature at the nozzle inlet.
  The temperature evolution is read from `Tc_vs_time_K.csv`.
