# Shape Optimization – modeFRONTIER

This folder documents the shape optimization activity performed using
the modeFRONTIER platform for the rocket nozzle divergent section.

Due to the size of the optimization database and workflow files,
the complete optimization environment is not stored directly in this
repository.

## Contents

- Complete modeFRONTIER workflow
- Optimization database and results
- Geometry parametrization and solver coupling
- Pareto front and post-processing data
